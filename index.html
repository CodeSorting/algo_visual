          4-Queens: 입력은 4개의 퀸
          01

          완전탐색 · 만들어보고 판단하기

          각 행에서 열을 하나씩 고르므로 완성 배치는 NN개입니다. 중간에 충돌해도 계속 배치합니다. N개를 모두 놓은 뒤 모든 퀸 쌍을 검사합니다.

          N = 4 → 4⁴ = 256개 완성 후보

          02

          백트래킹 · 불가능하면 아래는 생략하기

          새 퀸을 놓을 때 열과 두 대각선의 점유 상태를 검사합니다. 이미 충돌한 부분 배치는 뒤에 무엇을 놓아도 정답이 될 수 없으므로 그 하위 가지 전체를 생략합니다.

          [0, 0, −, −] → 남은 4² = 16개 생략

          점유 배열의 의미

          usedCols[c]: c열 사용 여부 · diagDown[r − c + N − 1]: ↘ 대각선 · diagUp[r + c]: ↙ 대각선. 안전한 퀸을 확정할 때 1, 되돌아올 때 0으로 바꿉니다.

          이 페이지의 구현을 기준으로 한 복잡도
          기준완전탐색백트래킹
          시간Θ(N² · NN)O(N · N!)의 보수적 상한 · 여전히 지수적 탐색
          근거NN개의 완성 배치마다 N(N−1)/2쌍을 모두 검사중복 열을 허용하지 않는 유효 접두 배치만 확장. 각 재귀 호출에서 N개의 열을 시도하고 점유 배열로 O(1)에 검사
          작업 공간O(N) · 현재 배치와 재귀 스택O(N) · 배치·점유 배열·재귀 스택

          전체 해를 저장하는 공간과 시각화용 단계·트리 기록은 알고리즘의 작업 공간과 별도입니다. 이 학습기는 되돌아보기를 위해 기록을 보관하며 N=4만 사용합니다. N≥2 기준 분석입니다.

          애니메이션보다 선택의 이유를 먼저 보세요.

          4-Queens에서 ‘첫 가지치기’로 이동해 같은 열의 두 퀸과 점유 배열을 확인하세요. 이전·다음으로 임시 배치, 충돌 검사, 가지치기, 제거를 비교한 뒤, 첫 번째 해와 전체 결과를 살펴보면 됩니다.
