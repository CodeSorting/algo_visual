    03 / UNDER THE HOOD

    기억할 정보가 다르면, 다음 이동도 달라집니다.

    01 / KMP

    불일치 전의 정보를 남깁니다.

    LPS[j]는 P[0..j]의 진접두사와 접미사가 같은 가장 긴 길이입니다. ABAB에서는 AB를 재사용하므로 마지막 값이 2입니다.

    불일치가 생기면 j = LPS[j−1]로 더 짧은 후보를 고릅니다. 본문의 위치 i를 뒤로 옮길 필요가 없습니다. 일치 후에도 같은 규칙을 적용하면 겹치는 결과를 놓치지 않습니다.

    ABAB → LPS = [0, 0, 1, 2]
    02 / RABIN–KARP

    창을 옮기며 지문을 갱신합니다.

    패턴 길이만큼의 검색 창을 해시 값으로 표현합니다. 다음 창에서는 맨 앞 문자의 기여를 빼고, 자릿값을 한 칸 옮긴 뒤 새 문자를 더합니다.

    해시가 같으면 실제 문자를 비교합니다. 충돌은 서로 다른 문자열이 같은 해시를 갖는 경우이므로, 이 검증을 마친 뒤에만 정답으로 기록합니다.

    h′ = ((h − out × high) × b + in) mod q

    이 구현을 기준으로 한 복잡도

    n = 텍스트 길이 · m = 패턴 길이 · 1 ≤ m ≤ n
    기준KMP · LPS 방식Rabin–Karp · 실제 문자 검증
    전처리O(m) · LPS 구성O(m) · 초기 해시와 high
    전체 시간O(n + m) · 최악에도 선형O(n + m + vm), 최악 O(nm)
    핵심 보조 공간O(m) · LPS 배열O(1) · 해시와 인덱스
    시간이 드는 이유i는 전진만 하고 j의 후퇴 총량도 O(n)각 창의 해시 갱신은 O(1), 해시가 같은 v개 창은 각각 최대 m자 검증

    v는 실제 정답을 포함하여 해시가 같았던 창의 수입니다. 따라서 충돌이 없어도 반복 문자열의 겹치는 정답을 모두 검증하면 O(nm)이 될 수 있습니다. 검증 비용이 O(n + m)인 입력에서는 전체도 선형입니다. 이 실험의 고정된 q = 101 또는 5만으로 평균 선형 시간을 보장하지 않습니다.

    표는 핵심 알고리즘의 작업 공간 기준입니다. 이 웹사이트는 유니코드 입력 배열 O(n + m), 정답 O(k), 단계별 되돌리기를 위한 기록을 추가로 저장합니다. 기록 길이를 s라 하면 배열 복사 때문에 최대 O(s(n + m))의 공간을 사용하며, 이 기록 비용은 위 복잡도에서 제외했습니다.
